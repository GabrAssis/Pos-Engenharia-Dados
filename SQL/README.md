# SQL

Anotações, consultas e desafios das aulas de SQL da pós em Engenharia de Dados.

## Conteúdos

| Módulo | Assuntos |
| --- | --- |
| [Criando Consultas com SQL](Criando%20Consultas%20com%20SQL/) | Filtros, operadores de comparação e lógicos, BETWEEN, IN, LIKE, DISTINCT, ordenação, concatenação e operações aritméticas. |
| [Manipulando Dados Através de Consultas](Manipulando%20Dados%20Atrav%C3%A9s%20de%20Consultas/) | Funções de texto, datas e números; tratamento de valores nulos com COALESCE e NULLIF. |
| [Estruturas Condicionais](Estruturas%20Condicionais/) | CASE WHEN, IIF e aplicação de condições em consultas. |
| [Agrupando e Resumindo Dados](Agrupando%20e%20Resumindo%20Dados/) | Funções de agregação, GROUP BY, HAVING e ordem lógica de execução. |

## Como estudar

1. Abra a pasta do módulo e escolha um arquivo `.sql`.
2. Leia os comentários de identificação da aula ou do desafio.
3. Execute e adapte as consultas no ambiente de banco utilizado nas aulas.
4. Registre dúvidas, erros e aprendizados nos comentários do próprio exercício.

As consultas dependem das tabelas usadas nas aulas. Há exemplos com funções do SQL Server, como `IIF` e `DATEADD`; ajustes podem ser necessários em outros bancos.

## Como adicionar uma aula

Use o [modelo para novas aulas](_MODELO_para_novas_aulas.sql), salve na pasta do módulo e escolha um nome que descreva o assunto.

Cada arquivo deve conter:

- **AULA:** nome ou assunto.
- **TIPO:** aula ou desafio.
- **O QUE FAZ:** explicação breve da consulta.
- Comentários antes de cada consulta para facilitar a revisão.

Os exercícios são registros de estudo e podem conter tentativas incompletas ou erros identificados nos comentários.

# Python

Área reservada para exercícios, anotações e práticas de Python da pós em Engenharia de Dados.

## Situação atual

Esta pasta ainda não contém exercícios de Python. Os projetos que já utilizam a linguagem estão na área de [Engenharia de Dados com IA](../Engenharia-de-Dados-IA/).

## Como organizar os próximos estudos

Crie pastas por módulo ou assunto, conforme as aulas forem avançando. Use nomes descritivos nos arquivos, como `listas_e_dicionarios.py`.

Em cada exercício, registre:

- O assunto da aula e o objetivo.
- O código desenvolvido.
- Um exemplo de entrada e saída, quando fizer sentido.
- Dúvidas e aprendizados em comentários.

## Como executar

No terminal do VS Code, entre na pasta do exercício e execute:

```powershell
python nome_do_arquivo.py
```

Quando houver dependências, documente a instalação e a configuração no README do exercício ou projeto.
